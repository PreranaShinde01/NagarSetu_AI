Context & Motivation

The Urban Civic Governance Crisis

Why legacy municipal portals and manual helpline systems fail in modern smart cities.

01 FRAGMENTED

Grievance Black Hole

  • • Citizens submit complaints across letters, calls, and WhatsApp with zero unified tracking.
  • • No transparent lifecycle: cases are closed on paper without physical site resolution.
  • • Complainants are never asked to verify the repair before ticket termination.
02 DUPLICATION

Duplicate Flooding

  • • A single prominent road pothole or water leak triggers 20-50 duplicate submissions.
  • • Controllers waste hours manually triaging and re-assigning identical reports.
  • • Multiple field teams get dispatched to the exact same spot, wasting civic budget.
03 EXCLUSION

Language & GIS Blindspots

  • • Traditional portals alienate grassroots citizens with rigid forms, lack of NLP, and slow manual routing.
  • • Zero spatial visibility: ward officers cannot view live GIS heatmap clusters.
  • • Critical P1 emergencies (pipeline explosions, live wires) breach SLA unmonitored.
💡 Target: Build an autonomous, spatial, bilingual closed-loop bridge between 300,000+ citizens and municipal crews.

Generative AI & Intelligent Civic Components

Three distinct intelligent engines embedded directly into the civic workflow.

🤖

1. Civic Assistant Chatbot

  • • Multilingual NLP: Converses naturally in multiple languages with adaptive tone and intent detection.
  • • Context-Aware Guidance: Explains P1-P4 priority tiers, municipal departments, and complaint filing steps.
  • • Zero-Failure Architecture: Backend REST AI service with instant client-side fallback engine that works offline.
  • • 1-Click Action Chips: Renders clickable pills that route directly to filing forms or case timelines.

2. AI Routing & Triage

  • • Automated Triage: Scans complaint text and classifies into 6 municipal departments.
  • • Severity & Priority Scoring: Assigns P1 (Critical), P2 (High), P3 (Medium), or P4 (Low) with automatic SLA targets.
  • • Confidence Metric: Displays 0-100% confidence rating with 1-click controller approval or override.
  • • Zero Bureaucratic Lag: Reduces routing from 3 days to under 200 milliseconds.
📍

3. Spatial Deduplication

  • • Haversine Distance Clustering: Computes spatial proximity radius of all active complaints.
  • • Semantic Similarity: Evaluates description tokens to identify co-located duplicates (e.g. 14 pothole reports).
  • • Master Parent Ticket: Groups duplicates into a single work order dispatch.
  • • Synchronized Updates: When the master ticket is resolved, all complainants receive resolution alerts.

System Engineering

End-to-End Technology Stack

Engineered for speed, offline reliability, strict privacy, and zero data corruption.

FRONTEND & DESKTOP SHELL
  • • React 18 + Vite 6: High-performance SPA with modular Context providers.
  • • Electron Framework: Packaged desktop shell with custom title bar and window controls.

BACKEND REST API SERVER
  • • Node.js + Express: Asynchronous modular REST API with ES Modules.
  • • JWT Authentication: Secure token generation with bcrypt password hashing.
  • • Helmet & Rate Limiting: Security headers and brute-force protection.
  • • Request Tracing: Injects X-Request-ID UUIDv4 on every transaction.
  • • Database Gatekeeper: Returns clean 503 errors with honest fallback if DB is offline.
DATABASE & DATA INTEGRITY
  • • MongoDB & Mongoose: 14 schema collections with GeoJSON spatial indexing.
  • • Atomic Sequential Counters: Thread-safe Counter model generating collision-free IDs.
  • • Immutable AuditLog: Append-only ledger recording all actor mutations for RTI.
  • • Tenant Isolation: Strict municipalityId scoping preventing cross-city data leaks.

Accountability

Automated SLA Engine & Escalation Hierarchy

Enforcing civic service guarantees through real-time countdown timers and automated escalation.

SERVICE LEVEL AGREEMENT (SLA) TIERS
P1 Critical (4 - 6 Hours) Pipeline burst, live wire, water contamination
P2 High (12 - 24 Hours) Deep pothole, fallen tree, streetlight outage
P3 Medium (24 - 48 Hours) Overflowing dustbins, drain blockage
P4 Low (72 - 96 Hours) Broken paver block, signage paint, encroachment
AUTOMATED ESCALATION HIERARCHY
  • • Level 1 Escalation (At Risk): When 75% of SLA buffer is consumed without worker dispatch, warning alert triggers on controller console.
  • • Level 2 Escalation (SLA Breach): Timer hits zero without resolution; case escalates to Department Officer and City Controller.
  • • Level 3 Escalation (Executive Review): Chronic breaches trigger direct executive notification to Municipal Commissioner (IAS).
  • • Immutable Event Logging: Every breach records target minutes, elapsed minutes, and cause into SLAEvents.
